Базовые действия:

-   Рывок:  Даёт бонусные 5 или 4 единиц действия которые можно потратить только на передвижение(синего цвета)
-   Перебежка:  Уменьшает шанс попадания при передвижении
-   Пинок:  Отбрасывает цель на 1 + значение навыка(определить навык) клеток

Как сделать:

-   Вынести все возможные статы игрока в его json файл
-   В game.py перенаправлять id действия в actions
-   Добавить массив всех активных эффектов на игроке в его json файл
-   При запуске игры сперва проверять базовое значение статов, потом прибавлять к нему эффекты
-   В actions в зависимости от поступающего действия добавлять его к игроку, или выполнять сходу
